另从阶段五本地备份按清单顺序选择第一条合法、未作废的真人“打开车门”录音 `member01_open_door_1.wav`，只复制到 Git 忽略的 `tmp/stage5-final-acceptance/`。选择依据是内容、非静音和无明显削波，不比较模型分数。SHA-256 为 `a5c1f7cc82a4f814078b328ed50347b94bd7c583462c7a4d37c0a231ef436cad`；频谱实测 `silence_detected=false`、`clipping_ratio=0.006839`。Whisper 原始输出为“打開車門”，现有通用规范化得到“打开车门”，没有使用期望文本替换 ASR，也没有让文件名或人工类别进入推理。

## 已知限制

- 三条音频只能证明当前软件路径真实执行，不能证明通用检测准确率。
- LA/PA 公开模型的训练语言和录音条件与中文座舱现场并不完全一致；阈值是统一安全策略，不是本阶段阈值校准实验。
- 当前扬声器重录样本发生 PA 漏检：`pa_raw_score=7.736411`、`pa_score=0.999564`、`replay_risk=0.000436`。系统保持官方标签方向，不反转标签或针对样本调阈值；样本由 LA 风险与安全链进入 REVIEW 且不签发令牌，不能将此表述为 PA 检测成功，也不能宣称跨设备通用准确率。
- 当前 Sara LA 对本地真人“打开车门”录音发生误报，最终进入 REVIEW；其 ASR、语义帧、证据需求和证据子图仍完整生成。
- Whisper Base 可能在重放或噪声输入上误识别；声学与后续安全门会限制执行。
- 模拟阵列通道是确定性区域标签，不是物理阵列波束形成或声源定位。
