# 阶段三验收说明

本阶段只实现高级推理、越狱防护与完整安全裁决闭环，不包含前端、WebSocket、音频、完整复核、授权令牌、车辆动作执行或 CAN。

## 验收链路

文本经真实 BGE 768 维归一化向量和 hnswlib 召回后，执行强制补召与证据质量评估；同轮快照时间作为新鲜度参考。随后依次执行横向记忆、单向纵向传播、可信审计因果修正、声明对齐、Grounding Failure、越狱风险聚合、16 项硬门和五维评分。所有中间量、节点 ID、传播路径、因果边、规则、实际权重、最终解释和耗时进入审计哈希链。

## 安全不变量

1. MISSING、TAMPERED、关键 STALE、三级越狱或任一物理硬规则不能被记忆、因果历史、紧急措辞或高软分抵消。
2. 低风险娱乐层不得反向提升驾驶或紧急层证据。
3. 冲突横向连接只降低可信度。
4. 因果后验非空、非负、严格归一化；历史不足明确标记 `insufficient`。
5. 只有独立质量侧表中 VALID 且 eligible 的记录参与学习。
6. 质量侧表更新不改变原审计哈希；正文或阶段三字段篡改会使验链失败。

## 冻结专项验证

- Cnec：权重 Csem/Ccov/Ctrust/Cjb/Cnec=`0.210/0.255/0.255/0.255/0.025`，总和 1，且 Cnec 不超过 Cjb 的十分之一。普通开门、音乐、模糊命令和仅含紧急措辞均为 0；障碍距离支持的制动为 0.9；真实紧急制动为 1。
- 索引稳定性：冷启动 `canonical_node_count=28`；连续 100 轮相同场景后仍为 28，`index_update_count=2700`、`deduplicated_count=2700`、`index_rebuild_count=1`、`degraded=false`。双源冲突显式新增两个真实来源后为 30。MISSING 和运行时派生节点不会进入全局索引。
- 因果人工环：A→B→C→A 在剪枝前确认为有环；确定性剪枝至少删除一条边并返回 `removed_edges.reason`，剪枝后通过 `is_directed_acyclic_graph`。反转输入顺序结果相同。
- 目标泄漏：当前轮因果输出 `feature_cutoff=pre_decision` 和非空 `used_features`；测试明确禁止 `final_decision`、`vehicle_execution` 及任何 `decision.*` 当前轮特征。
- 双重记忆：纵向公式为 `after=clamp(before+support_adjustment+risk_adjustment,0,1)`，`final_adjustment=after-before`；支持和风险通道均有真实路径，所有路径仅从高安全层流向低安全层并进入图和审计。
