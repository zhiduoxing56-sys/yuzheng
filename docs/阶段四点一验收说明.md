## 安全语义

`RuntimeCapabilityStatus` 是 Safety Gate、动态裁决、授权签发、执行前复查、健康、审计、工作流和 WebSocket 的共同事实源。真实 BGE 失败时进入 RESTRICTED：R3 可执行车控直接 BLOCK，R1/R2 最高 REVIEW，查询允许返回但 `actionable=false`，且禁止签发或执行令牌。hnswlib 单独失败时使用真实 BGE + 精确余弦，保持 FULL。

EvidenceRepository 使用 `evidence_type + source + entity_id` 稳定流键。动态流窗口为 16，轮次映射为 64；active turn 受保护，审计保存后清理 MISSING、冲突派生和解释节点。HNSW 继续使用既有稳定键，本轮图与 SQLite 审计保留完整节点。

因果输出将后验分布集中程度与决策置信度分离。少于两个有效节点时状态为 `SINGLE_NODE_UNDEFINED`；历史样本不足 20 条时为 `INSUFFICIENT_DATA`；两种情况 `decision_confidence=null`。达到阈值后才为 `AVAILABLE`。当前轮审计保存后才进入重建计数，重建失败保留上一稳定版本。
