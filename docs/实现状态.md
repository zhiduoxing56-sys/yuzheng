## 阶段一实测记录

- 编译检查：`python -m compileall -q backend/app backend/tests`，退出码 0。
- 首轮测试：15 项中 13 通过、2 失败；修复复合声明动作优先级和 SQLite 摘要列交叉校验后，全套 15 项通过。
- 最终测试：`15 passed in 0.23s`。
- EOF 格式化后的最终冒烟回归：`15 passed in 0.27s`。
- 实际 HTTP 场景：驻车驾驶员打开车门 `PASS`；80 km/h 行驶中打开车门 `BLOCK`；“把那个打开” `REVIEW`。
- 实际审计：SQLite 写入 3 条验收记录，`verify_chain()` 返回 `True`。
- 验证用 Uvicorn 进程已在请求结束后停止。

## 阶段一简化边界

- 文本输入不执行声学或 ASR 模型推理；审计中明确标记 `NOT_APPLICABLE_TEXT_INPUT` 和 `model_inference_performed=false`。
- 证据来自确定性车辆状态模拟器，不代表真实车机、传感器或 CAN 总线。
- `query_vector` 在阶段一保持空数组；未执行向量嵌入或索引检索。
- 安全分数只由语义质量和强制证据覆盖率计算；完整五维动态评分属于后续阶段。
- 审计已落 SQLite 并实现哈希链校验，但尚未提供审计查询/导出 HTTP 接口。
- 阶段一不执行车辆动作，`authorization_token`、车辆执行请求和反馈保持空值。
