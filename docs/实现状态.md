3. 显式状态覆盖 `vehicle_speed=null` 会保留为空值并生成 `MISSING` 节点；返回 `mandatory_evidence_missing=true`，命中 `MANDATORY_EVIDENCE_AVAILABLE` 并最终 `BLOCK`。

## 阶段五点一：LA/PA 观测模式（2026-08-02）

- 默认策略仍为 `enforce`，可通过进程启动前的 `YUZHENG_VOICE_TRUST_MODE=observe` 切换；非法值在启动时明确失败。模式在单个 `CommandPipeline` 生命周期内固定，不支持运行中静默切换。
- `observe` 不跳过模型：频谱、单一 LA、单一 PA、报告代码 2 可信评分、ASR、区域权限、WebSocket 和审计均继续执行；仅纯 LA/PA 的 REVIEW/BLOCK 不再覆盖原安全链结果，`authorization_effect_applied=false`。
- 输入有效性失败（静音/低能量或空转写）、区域权限失败、强制证据缺失、行驶中开门等安全门仍然 BLOCK；文本接口语义不受模式影响。
- 对外固定解释为：“声学防伪结果处于观测模式，当前不参与授权裁决。”该模式是当前 LA/PA 模型与中文座舱录音存在域偏移时的临时集成措施，不构成检测准确率声明。
- 三条既有真人录音经真实 HTTP 接口验收：查询速度经繁简规范化后为 `查询/速度`，最终 `PASS` 且查询不签发车控令牌；“播放音樂”当前对象未命中，最终 `REVIEW`；“打開車門”规范化为 `打开/车门`，证据齐全且最终 `PASS`，签发一次性授权令牌。三条声学结果均为 REVIEW，均记录 `authorization_effect_applied=false`，没有把观测分数伪装成授权依据。
