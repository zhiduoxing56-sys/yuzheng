# 裁决页贝叶斯风险展示设计说明

## 背景与目标

在裁决页右侧“查看裁决依据”和“诊断评分（不覆盖安全门）”之间增加一个同风格折叠项，展示只读贝叶斯诊断结果。

## 现状与约束

- 后端已提供 `GET /api/turns/{turn_id}/bayesian-diagnostic`。
- 该结果仅作展示，不影响既有裁决。
- 不展示安全概率、熵、模型版本、计算模式或缺失证据。

## 方案对比

### 方案一：单行摘要

- 优点：占用空间最小，与现有裁决页密度一致。
- 缺点：窄屏时可能自然换行。

### 方案二：风险与因素分两行

- 优点：信息更易扫读。
- 缺点：占用更多垂直空间。

### 方案三：二维表格

- 优点：结构最规整。
- 缺点：超过本次极简展示要求。

## 推荐方案

采用方案一。展开后仅显示：`贝叶斯风险概率 83.40% ｜ 风险因素：低照度 49.81% · 车辆速度 7.81% · 低能见度 0.23%`。

## 详细设计

### 架构

裁决页随轮次变化调用只读诊断接口，将第一条诊断结果传给 `DecisionResultDisplay`。

### 关键组件

- 前端贝叶斯诊断 TypeScript 类型。
- `getBayesianDiagnostic` API 方法。
- `DecisionResultDisplay` 中位于两个现有折叠项之间的新 `details`。

### 数据流 / 接口

展示 `risk_probability` 和按 `contribution` 降序的 `factor_contributions`。所有概率格式化为两位百分数。

### 异常与边界处理

请求失败、无结果或不支持时，仅显示 `--`；不增加错误提示。宽度不足时允许单行容器自然换行。

### 测试策略

- 验证新折叠项位于两个既有折叠项之间。
- 验证只显示风险概率和因素贡献。
- 验证空数据使用 `--`。

## 风险与待确认项

无。前端不读取或改变任何裁决字段。
