# 阶段五可信语音输入设计说明

## 背景与目标

阶段五只实现需求报告第 2.1.2 节可信输入层、第 2.1.3 节步骤 ① 至 ③、第 3.1 节和第 3.2.1 节。真实链路为：PC 麦克风或座位通道模拟输入，依次经过频谱异常分析、LA 合成音检测、PA 重放检测、报告公式的可信评分、中文 ASR、区域权限过滤，再复用既有语义、证据图和安全裁决流水线。

## 现状与约束

- 冻结基线 `e34ff158fae7314de6fa6b5575d407d33f6707d4` 的 87 项测试通过。
- 现有 `VoiceTrustResult` 已覆盖报告字段，但文本入口使用仅适用于文本直通的声学占位值。
- 现有 `TranscriptionResult` 尚未公开报告要求的 ASR 字段。
- `speaker_zone`、`speaker_role` 当前由文本请求提供；审计可保存语音和转写结构，但没有真实音频处理数据。
- 必须继续使用真实 BGE 与 hnswlib，不改变现有文本接口安全语义，不实现前端、CARLA、CAN 或台架。

## 方案对比

### 方案一：LA/PA 共用单一反欺骗模型

- 优点：内存占用较低，接线简单。
- 缺点：无法区分模型训练任务，LA 与 PA 解释边界不清晰。

### 方案二：LA、PA 使用独立公开模型（采用）

- 优点：LA 与 PA 各自执行真实波形推理，模型来源、版本、标签映射和失败状态可独立审计。
- 缺点：首次加载和常驻内存成本较高。

### 方案三：仅使用频谱统计规则

- 优点：无模型资产，运行轻量。
- 缺点：不满足本阶段对真实 LA/PA 模型推理和模型加载失败安全处理的验收要求。

## 推荐方案

LA 使用 `MelodyMachine/Deepfake-audio-detection-V2` 的 Wav2Vec2 二分类模型；PA 使用在 ASVspoof 2021 PA 数据上训练的 `Vansh180/deepfake-audio-wav2vec2`。两者均以 16 kHz 单声道波形执行离线推理并返回 bonafide 概率。ASR 使用本地缓存的 `openai/whisper-base`，模型按进程惰性加载并复用。模型或配置加载失败时返回明确安全失败，不生成伪造 PASS。

## 详细设计

### 架构与关键组件

- `voice.yaml`：频谱参数、模型标识和修订、可信评分权重与阈值、座位通道映射、区域权限权重与阈值。
- 音频组件：PC 录音设备采集、PCM WAV 解码、声道选择、16 kHz 重采样、SHA-256 摘要；原始音频只存在于请求处理内存。
- 频谱组件：从真实波形计算 RMS、频段能量、高频比、静音、削波和异常分数。
- LA/PA 组件：独立模型实例和标签映射，输出真实 bonafide 分数；频谱异常仅按配置作为模型结果的辅助惩罚。
- ASR 组件：Whisper 中文转写；无法给出可靠校准置信度时返回 `null`。
- 区域权限组件：严格使用报告代码 3 公式，输出 `permission_score`、`permission_label` 和 `risk_items`。

### 数据流与接口

- `POST /api/command/microphone` 从服务所在 PC 的真实录音设备采集。
- `POST /api/command/audio` 接收测试或模拟阵列使用的 PCM WAV 字节；座位区域由显式通道映射给出，审计记录定位来源，不声称真实阵列定位。
- 声学 BLOCK 在 ASR 前终止并保存明确的终止审计；REVIEW 和 PASS 执行 ASR。ASR 非空后只调用既有 `CommandPipeline`，共享同一 `turn_id`。
- 区域权限与声学 REVIEW/BLOCK 作为既有最终裁决的前置约束；硬规则仍优先，声学/区域风险不能签发授权令牌。

### 异常与边界处理

- 损坏 WAV、静音、过短音频、模型加载或推理失败均显式返回安全失败；不按文件名、来源标签或测试预期构造分数。
- PC 单麦克风不推断座位；区域必须来自明确请求配置。模拟阵列只按配置通道映射座位。
- WebSocket 事件在真实处理点发布；审计和事件只保存摘要、分数和模型元数据，不保存原始音频或模型密钥。

### 测试策略

- 单元测试覆盖波形解码、频谱、模型真实推理、可信公式、通道映射、区域公式、模型失败和 ASR 空结果。
- 接口与场景测试覆盖可信语音完整链、声学 REVIEW/BLOCK、同一 `turn_id`、七事件顺序、审计摘要、不落库原始音频、链完整性。
- 全量回归后再次验证真实 BGE/hnswlib、证据仓库有界、服务启动和真人/重放/合成音频样本。

## 风险与边界

- 两个公开反欺骗模型的训练域有限，结果仅作为本系统可信输入证据，不宣称覆盖全部中文 TTS、录音设备和重放环境。
- PC 麦克风真人验收依赖现场人员在录音窗口内发声；若没有物理发声，必须如实报告，不以 TTS 冒充真人。
