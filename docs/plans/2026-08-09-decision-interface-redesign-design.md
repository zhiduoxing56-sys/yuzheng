# 安全裁决首屏重构设计说明

## 背景与目标

仅重构前端第一个“安全裁决”界面，使其采用用户提供设计稿的浅色双栏视觉；其他路由、组件行为和后端契约保持不变。

## 已确认范围

- 顶部使用独立的窄品牌条，仅显示“语证”。
- 左上直接复用现有 `CommandInputPanel`，保留文本、音频上传和麦克风采集能力。
- 左下直接以格式化 JSON 展示后端返回的 `semantic_frame`。
- 右侧集中展示真实裁决结论、安全评分、五维评分和裁决原因。
- 页面底部仅展示后端运行状态和本次指令的真实端到端耗时。
- 不修改证据、复核、审计、演示和系统状态页面的视觉与行为。

## 数据与状态

- 语义帧、裁决结果和评分均来自持久化轮次展示接口，不填充示例值。
- 端到端耗时从用户提交开始计时，到匹配轮次的最终持久化展示可用为止，使用浏览器单调时钟 `performance.now()`；刷新后恢复的历史轮次不伪造耗时。
- 初始、处理中、完成、失败和部分完成状态分别提供明确反馈。
- PASS、REVIEW、BLOCK 分别使用绿、橙、红三种语义色。

## 响应式与验证

- 宽屏为左侧输入/语义帧、右侧裁决结果双栏。
- 窄屏按输入、语义帧、裁决结果、状态栏顺序单栏排列。
- 通过 TypeScript、Vitest、生产构建和浏览器页面检查验证。
