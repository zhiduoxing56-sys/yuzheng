## Epoch 流程

每个 epoch 先完成 TRAIN forward/backward/clip/optimizer/scheduler，再在 `eval + no_grad` 下评估 VALIDATION。逐 epoch 记录五项 train/validation loss、梯度范数、learning rate、时长、全量 validation metrics、raw argmax UFAR 与参数更新 checksum。

至少完成 2 个 epoch。仅当 validation safety gates 通过后，按 Stage 4B `PRIMARY_QUALITY_SCORE` 选择 best；patience 从首个合格 best 开始累计。非 finite loss/gradient 立即中止。

## Checkpoint 与验收

best/last 保存 state_dict、模型/训练配置、标签映射、backbone revision、dataset manifest hash 与 checkpoint SHA256，不保存整模型 pickle。实验结束后保持 `TEST_EVALUATION_EXECUTED=NO`、`SAFETY_GOLD_EVALUATION_EXECUTED=NO`，等待人工验证 validation 结果。
