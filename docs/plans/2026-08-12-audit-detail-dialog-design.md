# 审计详情同风格弹窗设计

## 目标

审计列表中的行点击和“查看详情”只在当前页面打开浅色同风格弹窗，不再导航到独立暗色详情页。

## 设计

- `AuditsPage` 保存当前选中的 `auditId`，不修改地址和列表状态。
- 弹窗通过现有 `useAuditDetail` 读取唯一的 `AuditDetailView`，复用人类可读详情区块。
- 弹窗提供加载、失败重试、刷新、遮罩关闭、关闭按钮和 Escape 关闭。
- 样式限定在审计弹窗作用域内，使用审计列表页的浅色蓝白视觉，不修改全局暗色主题。
- 不展示或复制旧工程型详情字段；技术语义帧仍留在既有技术入口。

## 验证

- 点击“查看详情”后当前路由不变并出现模态对话框。
- 关闭弹窗后列表保持原状态。
- 前端类型检查、构建和审计页回归测试通过。
