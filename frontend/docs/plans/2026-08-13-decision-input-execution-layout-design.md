# 裁决页输入与执行区布局调整设计说明

## 背景与目标

裁决页指令输入区域偏高，执行按钮周围的说明文字和面板外框占用额外空间。本次将输入区域减少一行，并让执行按钮直接显示在页面中。

## 约束

- 不修改颜色、字体、字号、按钮样式或整体视觉风格。
- 不修改后端、接口、令牌状态、按钮禁用条件或执行逻辑。
- 保留执行后的成功或失败结果反馈。

## 方案

三种输入模式共用的输入区域由三行高度缩减为两行高度，并删除对应的第三条横向引导线。执行区删除令牌说明、无令牌说明和操作提示，移除面板边框、背景和内边距，仅保留原按钮及执行后动态结果。

## 验证

运行前端生产构建和相关测试，确认按钮行为与执行结果渲染保持不变。
