# 裁决页语义帧紧凑布局设计说明

## 背景与目标

裁决页语义帧解析区域的摘要和子意图卡片纵向留白偏多。本次只压缩布局，并移除子意图中的“参数”展示行。

## 约束

- 保持现有颜色、字体、字号、边框、圆角和整体视觉风格。
- 不修改后端、接口、语义帧数据结构或裁决逻辑。
- 小屏继续使用现有单列响应式布局。

## 实施方案

保留摘要和子意图卡片的双列结构，缩小容器内边距、网格间距、卡片间距和标题下间距，并适当收紧信息区行高。前端不再渲染子意图的 `value` 参数项，但数据合同保持不变。

## 验证

更新组件测试，确认“参数”标签及其值不再展示，同时运行前端测试和生产构建。
