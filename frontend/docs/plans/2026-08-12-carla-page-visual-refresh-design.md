# CARLA 模拟器页面视觉调整设计说明

## 背景与目标

当前模拟器页面使用独立的深色行内样式，与裁决、证据检索和审计记录页面的蓝白视觉体系不一致。此次调整只修改布局、字体、字号和颜色，不修改接口、状态管理、事件处理或后端。

## 已确认方案

- 桌面端主体采用左右等宽两栏，尽量填满页面可用区域。
- 左栏依次展示“CARLA 模拟画面”和当前车辆状态。
- 右栏展示全部控制项，采用两列卡片布局，避免纵向内容超出页面。
- 页面统一使用前三页的蓝白背景、蓝色描边、宋体标题和微软雅黑正文。
- 删除推流参数、操作提示及页面描述等非必要的小字号解释文案。
- 保留操作结果反馈，因为它属于控制操作的必要状态信息。
- 窄屏下改为单栏，控制卡片再根据空间自动降为一列。

## 边界与验证

- 不改变任何 API 调用、请求参数、车辆状态字段或按钮行为。
- 通过 TypeScript 检查和生产构建验证结构与样式调整未破坏前端。
- 检查变更范围仅限本设计文档、CARLA 页面组件及视觉样式表。
