# Approved-44 用户控制对象清单

`DISTINCT_USER_CONTROL_OBJECT_COUNT = 35`

归并口径：同一物理/功能目标下的多能力合并（例如车门开合+锁、行李厢开合+锁、座椅各调节维度、外后视镜各控制）；具有独立用户目标和独立安全语义的灯、挡位/锁止/传动部件不因同属一个功能族而强行合并。
